# HR 法律法规知识库

独立网站：`https://hosamzj.github.io/hr-compliance/`

## 功能

- 跟踪中国大陆劳动、用工、社保、商业道德相关法律法规，当前覆盖 **40 部** 法规。
- 每月自动检查官方来源是否有更新。
- 按 URL 去重：多部法规共享同一页面时只抓取一次，合并为一条变更通知，避免刷屏。
- 检测到更新时自动生成简要“更新说明”（基于页面文本差异提取关键变化片段）。
- 有更新时通过邮件通知：
  - `sam.huo@te.com`
  - `fiona.lu@te.com`
- 网站首页顶部展示“本期更新摘要”，法规卡片和更新记录中均显示更新说明。
- 通知邮箱已配置，不在网站公开展示；邮件发送账号：`hosamzj@163.com`（通过 Himalaya CLI 配置）。

## 实现说明

采用页面哈希 + 文本快照监控方案：

- 为每部法规指定官方或最稳定的监控 URL（`data/laws.json` 中 `url` 字段）。
- 脚本按 URL 去重抓取，去除 HTML 标签/脚本/样式后计算 SHA-256 哈希并保存文本快照（`data/state.json`）。
- 比对当前哈希与上次哈希判断是否有更新；有更新时通过 `difflib` 提取关键变化片段生成“更新说明”。
- 更新说明写入 `data/laws.json`、`data/history.json`，并在网站和邮件中展示。
- 对全国人大法律数据库 SPA（`flk.npc.gov.cn`）和反爬页面（中纪委等），当前先监控页面外壳变化并提示需进一步人工确认；后续可接入无头浏览器或官方 API 实现正文级监控。
