# HR 法律法规知识库

独立网站：`https://hosamzj.github.io/hr-compliance/`

## 功能

- 跟踪中国大陆核心劳动、用工、社保相关法律法规
- 每月自动检查官方来源是否有更新
- 检测到更新时自动生成简要“更新说明”（基于页面文本差异提取关键变化片段）
- 有更新时通过微信 + 邮件通知，邮件正文中包含更新说明
- 网站首页顶部展示“本期更新摘要”，法规卡片和更新记录中均显示更新说明
- 通知邮箱已配置，不在网站公开展示
- 邮件发送账号：`hosamzj@163.com`（通过 Himalaya CLI 配置）

## 监控法规

1. 中华人民共和国劳动法
2. 中华人民共和国劳动合同法
3. 中华人民共和国社会保险法

7. 职工带薪年休假条例

## 实现说明

v1 采用页面哈希 + 文本快照监控方案：

- 每月抓取国务院政策库首页（`https://www.gov.cn/zhengce/index.htm`）的 HTML 内容
- 比对页面哈希判断是否有变化，同时保存文本快照
- 若页面变化，通过文本差异（difflib）提取关键变化片段，自动生成“更新说明”
- 更新说明会写入 `data/laws.json`、`data/history.json`，并包含在邮件和网站中

> 当前版本 7 部法规共用同一个政策库首页 URL，因此该页面一旦有变化，7 部法规会同时标记为“有更新”并共享同一份更新说明。后续版本将尝试接入官方 API 或按单部法规页面拆分抓取，实现更精确到法规/政策条目的监控。
